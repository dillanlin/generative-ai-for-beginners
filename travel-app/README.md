# 旅遊行程 App

一套可以重複使用的旅遊行程 App。**引擎共用一份，每趟旅程一個資料夾** —— 下次去別的地方玩，
複製一個範本資料夾就是一趟新旅程，彼此的行程、記帳、勾選狀態完全獨立。

純前端（HTML + CSS + 原生 JavaScript），沒有建置流程、沒有後端，可加到手機主畫面當 App 用。

---

目前內建 4 趟：**宮古島 6天5夜**、**普吉島 4天3夜**、**富國島 4天3夜**、**長灘島 4天3夜**
（後三趟是參考網路攻略擬的範本行程，航班／飯店／座標都是示意值，請依實際訂位修改）。

## 開新的一趟旅程

### 方法 1：首頁按鈕（最快，不用碰程式碼）

首頁最下面的 **「＋ 新增一趟旅程」** → 填標題、日期、成員、幣別、地圖中心 → 建立後直接進入編輯。
天數會依日期自動排好，接著在 App 內把每天的行程、航班、清單補上就好。

這種旅程存在**這台裝置的瀏覽器**裡，首頁卡片右上角有 ✕ 可以刪掉。
想長久保存或換手機用，進去按「工具箱 → 行程設定 → **匯出 trip.js**」，
再照下面方法 2 放進資料夾即可。

### 方法 2：資料夾（永久保存、可分享、可裝成獨立 App）

```bash
cd travel-app
cp -r trips/_template trips/kyoto-2026-10      # 1. 複製範本，資料夾名字自己取
```

**2.** 編 `trips/kyoto-2026-10/trip.js` 最上面的 `meta`，最少改這 6 個欄位就能跑：

```js
meta: {
  id: 'kyoto-2026-10',           // ★ 必須唯一，建議跟資料夾同名（App 靠它分開存資料）
  title: '京都 5天4夜',
  subtitleEn: 'KYOTO · JAPAN',
  startDate: '2026-10-01',
  endDate: '2026-10-05',
  center: [35.0116, 135.7681],   // 地圖中心，從 Google Maps 網址 @ 後面複製
}
```

**3.** 在 `trips.js` 加一行，首頁就會出現這趟旅程：

```js
{ folder: 'kyoto-2026-10', title: '京都 5天4夜', sub: 'KYOTO · JAPAN', range: '2026/10/01 – 10/05', emoji: '⛩' }
```

剩下的（每天要去哪、航班、必買清單……）**直接在 App 裡面編就好**，不用再回來改檔案。
順手的話也可以先在 `trip.js` 裡把 `days` 打好——兩種方式都行。

> 順便：`trips/_template/index.html` 和 `manifest.webmanifest` 裡有兩處寫著「我的旅程」，
> 想讓手機主畫面顯示正確名字的話，一起改成新旅程的名稱。

## 怎麼跑

```bash
cd travel-app
python3 -m http.server 8080
# 瀏覽器打開 http://localhost:8080  → 選一趟旅程
```

> 直接雙擊 `index.html` 也看得到，但離線快取（Service Worker）和天氣 API 需要用 `http://` 開啟。

**加到手機主畫面**：用手機瀏覽器開啟該趟旅程的網址 → 分享 → 加入主畫面。
之後開啟就是全螢幕、沒有網址列。每趟旅程可以各自加一個 icon。

## App 裡面可以編輯什麼

**全部都可以。** 不用碰程式碼也能把一趟空白旅程從頭建起來。

| 位置 | 可以改的東西 |
| --- | --- |
| 工具箱 → **行程設定** → 基本資料 | 標題、副標、**出發／回程日**（天數會自動增減）、兩位成員名字、幣別與匯率、地圖中心與縮放、天氣座標、頁尾標語 |
| 行程設定 → 天數 | 新增一天、刪除一天（後面日期自動遞補）、改每天的主題名稱 |
| 行程設定 → 航班 | 航空公司、去回程班次／時間／機場代碼、備註 |
| 行程設定 → 租車 | 區塊標題、任意「標籤 \| 內容」列、撥號電話 |
| 行程設定 → 必買清單 | 新增／刪除分組，改標題、圖示、顏色，用一行一項的方式編項目 |
| 每天 → **編輯行程** | 新增／編輯／刪除停點，按住 `≡` 拖曳排序，時間、分類、預約徽章、補充資訊、提醒小卡、Google Maps 連結、電話 |
| 匯率換算 | 直接改匯率，全 App（含記帳換算）一起更新 |
| 記帳分帳 | 新增／刪除每一筆，三種分帳方式 |

**改完怎麼存回檔案？** 行程設定 → **「匯出 trip.js」**，下載到的檔案直接覆蓋
`trips/<你的旅程>/trip.js` 就好。這樣換手機、清瀏覽器、分享給別人都不會掉。

**App 內編輯 vs. trip.js 誰贏？**
只要你在 App 內動過任何東西，之後就以本機版本為準（`trip.js` 的改動不會蓋掉你的編輯）。
想切回檔案版本，按「還原成 trip.js」即可（記帳與勾選狀態不受影響）。

## 功能一覽

| 畫面 | 功能 |
| --- | --- |
| **首頁** | 所有旅程的清單 + 「＋ 新增一趟旅程」按鈕；自建的旅程可以直接刪除 |
| **上一頁 / 下一頁** | 每天行程最下方有前後一天的按鈕，會顯示那天的日期與主題，不用滑回頂端切分頁 |
| **頁首地圖** | Leaflet + OpenStreetMap；當天景點依序編號成圖釘、虛線連成路線；點圖釘跳出小卡可開 Google 地圖或撥號。工具箱頁改顯示整趟旅程的所有點 |
| **Day 分頁** | 橫向滑動切換，已過去的日子淡化，捲動時頁首地圖自動縮小 |
| **每日時間軸** | 分類標籤、「✓ 已預約」徽章、車程／營業時間／訂單編號、黃色提醒小卡、地圖／撥號按鈕、可展開的「更多餐廳備案」。當天當下的行程會亮起 |
| **一鍵導航** | 把當天所有停點串成一條 Google Maps 駕車路線 |
| **航班 · 天氣** | 去回程航班卡、租車／住宿資訊、依旅程日期抓 [Open-Meteo](https://open-meteo.com/) 即時預報（抓不到就用 `trip.js` 的備份值） |
| **必買 & 注意** | 分組清單、進度條、勾選劃線、永久保存 |
| **匯率換算** | 雙向即時換算、匯率可改、金額快捷鍵 |
| **記帳分帳** | 兩人記帳，均分／代墊全額／各付各的，自動算「誰要給誰多少」，匯出 CSV（Excel 直接開，UTF-8 BOM 不亂碼） |
| **回憶模式** | 旅程結束後最後一天標「旅程已完成」，其他過去的日子標「這天已結束」 |
| **離線可用** | Service Worker 快取 App 本體與看過的地圖圖磚，出國沒網路也打得開 |

## 檔案結構

```
travel-app/
├── index.html                 # 首頁：旅程清單
├── trips.js                   # ★ 旅程註冊表（開新旅程時加一行）
├── engine/                    # 共用引擎，不用改
│   ├── app.js                 #   全部邏輯
│   ├── styles.css             #   全部樣式
│   ├── sw-core.js             #   離線快取
│   ├── icon.svg
│   └── icon-maskable.svg
└── trips/
    ├── _template/             # ★ 複製這個資料夾開新旅程
    │   ├── index.html         #   殼（只要改標題）
    │   ├── trip.js            #   ★ 這趟旅程的所有內容
    │   ├── manifest.webmanifest
    │   └── sw.js
    ├── custom/                # 首頁「新增一趟旅程」用的共用殼（?id=xxx）
    ├── miyakojima-2026-07/    # 宮古島 6天5夜
    ├── phuket-2026-11/        # 普吉島 4天3夜
    ├── phuquoc-2026-12/       # 富國島 4天3夜
    └── boracay-2027-01/       # 長灘島 4天3夜
```

一趟旅程只有 `trip.js` 需要動；`index.html` / `manifest.webmanifest` 只有標題要改；
`sw.js` 完全不用改。

## trip.js 欄位說明

`trips/_template/trip.js` 每個欄位都有註解，這裡只補行程停點的完整格式：

```js
{
  id: 'd1-3',                    // 唯一 ID
  time: '15:20',                 // 24 小時制
  cat: '午餐',                   // 機場/景點/早餐/午餐/晚餐/咖啡/住宿/水上/手作/溫泉/購物/交通
  title: 'Blue Turtle',
  subtitle: '伊良部島海景餐廳',
  booked: '已預約 15:20',         // 沒預約就不要寫這行
  lat: 24.8203, lng: 125.1553,    // 有座標才會出現在地圖上
  mapUrl: '...',                  // 只有短連結、抓不到座標時才用
  tel: '+81...',
  meta: [{ icon: 'car', text: '取車後約 10 分' }],   // icon: car / clock / ticket / walk
  tip: '龍蝦／漢堡咖哩…',                             // 黃色提醒小卡
  alts: { label: '更多餐廳備案（3 間）', items: [{ name: '店名', note: '4.5★' }] }
}
```

## 兩人同步

目前是**本機儲存**：每支手機各自保存。要同步時用行程設定的
「匯出 JSON」把檔案傳給旅伴，對方按「匯入 JSON」即可（行程、記帳、清單、匯率會一起帶過去）。
想要真正的即時雲端同步，需要另外接後端或 Firebase／Supabase 之類的服務。

## 相依套件

只有地圖用到 [Leaflet 1.9.4](https://leafletjs.com/)，從 unpkg CDN 載入（含 SRI 雜湊）。
想完全離線自帶的話，把 `leaflet.js` / `leaflet.css` / `images/` 放到 `engine/vendor/`，
再改掉各旅程 `index.html` 的兩個路徑即可。
地圖圖磚來自 OpenStreetMap，天氣來自 Open-Meteo，兩者都不需要 API key。

## 已知限制

- 圖磚與天氣需要網路；離線時用快取或 `trip.js` 的備份值。
- Google Maps 導航路線最多帶 9 個中途點（Google 網址參數上限）。
- 每天的日期由「出發日 + 第幾天」自動排出，所以刪掉中間某天，後面幾天的日期會往前遞補。
- 天氣預報只有出發前約 16 天內才抓得到（Open-Meteo 的預報範圍），更早只會顯示 `trip.js` 裡的 `fallback` 值。
- 首頁「新增一趟旅程」建立的行程只存在該裝置的瀏覽器，清除瀏覽資料就會消失 —— 要留就匯出 trip.js。
- 必買清單的勾選狀態靠項目 `id` 記；在編輯框裡改掉某項的**名稱**會被當成新項目，勾選會清掉（沒改名稱的都會保留）。
