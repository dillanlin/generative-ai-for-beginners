# 宮古島 6天5夜 · 旅遊行程 App

依照示範影片做的雙人旅遊行程 App。純前端（HTML + CSS + 原生 JavaScript），沒有建置流程、沒有後端，
所有資料存在瀏覽器的 `localStorage`，可以加到 iPhone / Android 主畫面當成 App 用。

## 怎麼跑

```bash
cd travel-app
python3 -m http.server 8080
# 瀏覽器打開 http://localhost:8080
```

> 直接雙擊 `index.html` 也能看，但 Service Worker（離線快取）和天氣 API 需要用 `http://` 開啟才會運作。

**加到手機主畫面**：用手機瀏覽器開啟網址 → 分享 → 加入主畫面。之後開啟就是全螢幕、沒有網址列，
行程與記帳都留在手機裡，離線也打得開。

## 功能一覽

| 畫面 | 功能 |
| --- | --- |
| **首頁地圖** | Leaflet + OpenStreetMap；當天景點依序編號成圖釘、虛線連成路線；點圖釘跳出小卡，可直接開 Google 地圖或撥號。切到工具箱頁時改顯示整趟旅程的所有點。 |
| **Day 1–6 分頁** | 橫向滑動切換；已過去的日子會淡化。捲動時頁首地圖會自動縮小。 |
| **每日行程時間軸** | 左側時間刻度＋圓點，卡片含分類標籤、「✓ 已預約」徽章、車程／營業時間／訂單編號、黃色提醒小卡、地圖／撥號按鈕，以及可展開的「更多餐廳備案」。當天當下的行程會亮起，過去的會變灰。 |
| **一鍵導航** | 「開啟當天 Google 導航路線」把當天所有停點串成一條 Google Maps 路線（起點、終點＋最多 9 個中途點）。 |
| **工具箱**（右下紫色按鈕） | 四張卡：航班 · 天氣、必買 & 注意、匯率換算、記帳分帳。 |
| **航班 · 天氣** | 去回程航班卡、TOYOTA 租車完整資訊（可直接撥給店家）、六天天氣預報。天氣走 [Open-Meteo](https://open-meteo.com/) 即時抓取，抓不到（離線／日期已過）就顯示 `data.js` 內建的備份值。 |
| **必買 & 注意** | 24 項採買清單＋行前提醒，分五組；打勾有進度條，勾過的會劃掉，狀態永久保存。 |
| **匯率換算** | 日幣 ⇄ 台幣雙向即時換算，匯率可自行修改，另有 ¥500～¥30,000 快捷鍵。 |
| **記帳分帳** | 兩人記帳：誰付的、分類、均分／代墊全額／各付各的三種分帳方式；自動算出「誰要給誰多少錢」（同時顯示台幣），可匯出 CSV（Excel 直接開，含 UTF-8 BOM 不會亂碼）。 |
| **編輯行程** | 新增／編輯／刪除行程，按住 `≡` 拖曳排序（支援觸控），新增後依時間自動排序。可貼 Google Maps 連結自動抓座標。另可匯出／匯入整份行程 JSON 給旅伴同步，或一鍵重設為預設行程。 |
| **回憶模式** | 旅程結束後最後一天會標示「旅程已完成 · 回憶模式」，其他已過去的日子標示「這天已結束」。 |
| **離線可用** | Service Worker 快取 App 本體與看過的地圖圖磚，出國沒網路也打得開。 |

## 檔案結構

```
travel-app/
├── index.html              # 頁面骨架（頁首地圖、分頁列、內容區、FAB、表單彈窗）
├── manifest.webmanifest    # PWA 設定
├── sw.js                   # 離線快取
└── assets/
    ├── data.js             # ★ 行程／航班／租車／天氣／必買清單的預設資料
    ├── app.js              # 所有邏輯（路由、渲染、地圖、記帳、匯率、編輯）
    ├── styles.css          # 樣式
    ├── icon.svg
    └── icon-maskable.svg
```

## 要改成自己的旅程

`assets/data.js` 是唯一需要動的檔案：

- `meta`：標題、日期區間、兩位成員名字、地圖中心點、預設匯率。
- `flights` / `car`：航班與租車資訊。
- `weather`：緯經度、備份預報值。
- `shopping`：必買清單分組（`id` 請保持唯一，勾選狀態是靠 `id` 記的）。
- `days[].items[]`：每個停點。欄位說明——

  ```js
  {
    id: 'd1-3',                 // 唯一 ID
    time: '15:20',              // 24 小時制
    cat: '午餐',                // 機場/景點/早餐/午餐/晚餐/咖啡/住宿/水上/手作/溫泉/購物/交通
    title: 'Blue Turtle',
    subtitle: '伊良部島海景餐廳',
    booked: '已預約 15:20',      // 沒有就省略
    lat: 24.8203, lng: 125.1553, // 有座標才會出現在地圖上
    mapUrl: '...',               // 只有短連結、抓不到座標時才用這個
    tel: '+81...',
    meta: [{ icon: 'car', text: '取車後約 10 分' }],   // icon: car/clock/ticket/walk
    tip: '龍蝦／漢堡咖哩…',                              // 黃色提醒小卡
    alts: { label: '更多餐廳備案（3 間）', items: [{ name, note }] }
  }
  ```

改完 `data.js` 後，若 App 內已經有編輯過的資料，要在「編輯行程 → 重設為預設行程」按一下才會吃到新的預設值。

## 兩人同步

目前是**本機儲存**：每支手機各自保存自己的資料。要同步時用「編輯行程 → 匯出行程 JSON」把檔案傳給對方，
對方按「匯入行程」即可（行程、記帳、採買清單、匯率會一起帶過去）。
若之後想改成真正的即時雲端同步，需要另外接一個後端或 Firebase／Supabase 之類的服務。

## 相依套件

只有地圖用到 [Leaflet 1.9.4](https://leafletjs.com/)，從 unpkg CDN 載入（`index.html` 內含 SRI 雜湊）。
若想完全離線自帶，把 `leaflet.js` / `leaflet.css` 和 `images/` 下載到 `assets/vendor/` 並改掉 `index.html` 的兩個路徑即可。
地圖圖磚來自 OpenStreetMap，天氣來自 Open-Meteo，兩者都不需要 API key。

## 已知限制

- 圖磚與天氣需要網路；離線時會用快取或內建備份值。
- Google Maps 導航路線最多帶 9 個中途點（Google 的網址參數上限）。
- `data.js` 內的座標為概略值，實際使用前建議在「編輯行程」貼上 Google Maps 完整連結校正。
